RETENTION / STORAGE POLICY
Retention semanticsHigh-frequency samples are kept raw for the configured window, then rolled into permanent hourly count, average, minimum and maximum records. This preserves long-term trends without allowing one-second sampling to grow the database without bound.
GUI composition / animation diagnosticsmeasured vs not yet measured
WHAT IS MEASURED TODAY
Current measurement boundaryProcess session IDs and visible-window counts show which processes own visible top-level windows. PDH samples DPC, paging, faults, memory and disk counters. WPR captures an ETL trace only when an approved trace is running. SENTINEL does not yet decode DWM frame-present events, per-window frame pacing, dropped frames or input-to-photon latency into an FPS timeline. Use Windows Performance Analyzer / GPUView on the captured ETL for that deeper analysis; do not infer animation smoothness from DPC counters alone.
